## Pattern observé

`declare module "pkg"` inline dans un fichier avec imports = module augmentation (TS2666), pas déclaration ambiante. Créer un `.d.ts` séparé.

## Détail

En TypeScript, un fichier contenant au moins un `import` ou `export` est un **module**. Dans ce contexte, `declare module "apngasm-bin" { ... }` est traité comme une **augmentation de module** (ajout à un module existant), pas comme une déclaration ambiante de module.

Les augmentations de modules ne peuvent pas redéfinir l'export default (TS2666 : "Exports and export assignments are not permitted in module augmentations"). L'import `apngasm` devient alors un type uniquement (TS2693).

**Fix :** créer un fichier `.d.ts` séparé **sans aucun import/export** (contexte script). Dans ce contexte, `declare module "pkg"` est une déclaration ambiante valide qui définit les types du module complet. Le fichier est inclus automatiquement si le tsconfig couvre son dossier (`"include": ["src/**/*"]`).

```typescript
// src/apngasm-bin.d.ts (aucun import — contexte script)
declare module "apngasm-bin" {
  const path: string;
  export default path;
}
```
