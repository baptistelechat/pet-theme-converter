# LRN-015 — Hook graphify ≠ `--update` : comportements distincts sur les types de fichiers

| Pattern observé                                                                                                                                 | Contexte                                          | Application future                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Le hook post-commit ne traite que les fichiers code via AST (sans LLM). `/graphify . --update` traite tous les types (docs via LLM si modifiés) | Discussion workflow graphify sur projet 100% docs | Sur tout projet avec docs importantes : préférer `--update` manuel au hook, plus complet et sans surprise |

## Références

- [BDR-013](../decisions/BDR-013.md) — décision de retirer le hook motivée par ce pattern
