# LRN-028 — Patch de review référençant un script npm inexistant → reclassifier en defer

| Pattern observé                                                                                                                                                                                                                                             | Contexte                                                                                                                                                                                                | Application future                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Si un patch de code review demande d'ajouter une instruction documentaire qui référence un script npm absent de `package.json`, l'appliquer crée une doc erronée. Il faut reclassifier en defer et lier au defer existant qui couvre la création du script. | Session `/bmad-code-review 1.3` — P1 (`pnpm lint` dans la checklist PR de CONTRIBUTING.md) reclassifié car `scripts.lint` absent de `package.json` ; item ouvert depuis Story 1.1 dans deferred-work.md | Avant d'appliquer un patch documentaire qui cite une commande/script, vérifier son existence dans `package.json`. Si absent : reclassifier en defer et référencer l'item deferred-work concerné. |
