# LRN-037 — Fichiers de test temporaires : annoncer chaque phase comme étape visible

| Pattern observé                                                                                                                                                | Contexte                                                                                                                   | Application future                                                                                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand création + exécution + suppression de fichiers temporaires se succèdent rapidement, l'utilisateur peut manquer la validation et douter qu'elle a eu lieu | Story 2.2 — Baptiste n'a pas vu `test-2-2.mjs` créé puis supprimé, et a dû demander si les tests avaient bien été exécutés | Annoncer chaque phase comme message visible distinct : "je crée le script de test", "résultats : X/Y ✅", "je supprime les fichiers temporaires" — même si les 3 étapes sont dans la même réponse |
