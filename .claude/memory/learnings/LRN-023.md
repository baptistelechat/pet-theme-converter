# LRN-023 — Fichier story `done` absent : fallback via fichier de review

| Pattern observé                                                                                                                                                                                                                                                        | Contexte                                                                                                                                          | Application future                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le fichier story d'une story `done` peut être absent de `implementation-artifacts/` au moment de créer la story suivante. Le fichier de review (`reviews/epic-*/review-*.md`) + le journal de session fournissent un contexte équivalent pour les learnings critiques. | Création Story 1.2 — le fichier `1-1-initialisation-...md` n'existait pas dans le dossier, seul le review et `deferred-work.md` étaient présents. | Lors du step "previous story intelligence" de `bmad-create-story`, si le fichier story précédent est absent : chercher d'abord dans `reviews/epic-X-*/review-X-Y-*.md`, puis dans le journal de session. |
