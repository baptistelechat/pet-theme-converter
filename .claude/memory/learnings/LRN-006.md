# LRN-006 — PRDs BMAD multi-step : duplications inter-sections naturelles à merger en step-11

| Pattern observé                                                                                                   | Contexte                                                      | Application future                                                                                      |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Les steps 3 (Scope) et 8 (Scoping & Phased Development) génèrent des contenus qui se chevauchent structurellement | Workflow `/bmad-create-prd` — session PRD pet-theme-converter | En step-11-polish, prévoir systématiquement un audit de fusion des sections de scope/roadmap dupliquées |

Le step 3 produit une liste v0.1/v0.2/v0.3+ concise. Le step 8 produit la même structure mais enrichie (MVP strategy, risk mitigation, feature sets détaillés). Sans merge, le document contient deux sections "Scope" redondantes. La solution : supprimer la version step-3 et promouvoir la version step-8 sous un titre unifié (`Product Scope & Roadmap`).
