# LRN-035 — Grille Petdex : 8 colonnes = 8 frames par état (correction placeholder `frames: 9`)

| Pattern observé                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                                                                                                                      | Application future                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dans la grille Petdex standard (8 colonnes × 9 lignes, 1536×1872px), les 8 COLONNES correspondent aux 8 frames par état animé. Le champ `frames` dans STATE_MAPPING doit valoir `8` (pas `9`). Preuve : 1536px ÷ 8 colonnes = 192px/colonne → 8 colonnes = 8 frames. Le placeholder `frames: 9` dans l'architecture était mathématiquement faux — corrigé en Story 2.2. | Story 2.2 — analyse du format Codex standard avant l'implémentation de `detectGrid`. La confusion venait de "grille 8×9" interprétée comme "9 frames" alors que 9 = nombre de LIGNES (états). | `sliceFrames` (Story 2.3) doit itérer sur colonnes 0–7 (pas 0–8). Toute future modification du STATE_MAPPING doit raisonner en termes de colonnes (axe horizontal = frames) et de lignes (axe vertical = états). |

## Détail de la grille

```
Grille standard Petdex :
  Colonnes : 8  (→ 8 frames par état, axe horizontal)
  Lignes   : 9  (→ 9 états Petdex, axe vertical)
  Cellule  : 192 × 208 px
  Total    : 1536 × 1872 px

STATE_MAPPING correct :
  { row: 0..7, frames: 8 }  ← 8 états Clawd, lignes 0–7, 8 frames chacun
  La ligne 8 (9e état Petdex) n'est pas mappée sur Clawd.
```
