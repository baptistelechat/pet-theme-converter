# LRN-013 — TypeScript 5.x + tsup : préférer `"moduleResolution": "bundler"` à `"Node16"`

| Pattern observé                                                                                                                                                      | Contexte                                                                                           | Application future                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `"moduleResolution": "Node16"` impose des extensions `.js` explicites sur tous les imports relatifs TypeScript — inadapté quand un bundler (tsup) gère la résolution | Création de la Story 1.1 — tsconfig.json initialement spécifié avec `"Node16"` dans l'architecture | Tout nouveau `tsconfig.json` dans un projet TypeScript + tsup doit utiliser `"module": "ESNext"` + `"moduleResolution": "bundler"` |

`"moduleResolution": "bundler"` (TypeScript ≥ 4.9) est conçu exactement pour ce cas : le compilateur vérifie les types sans se soucier des extensions — tsup résout les modules au build.

Imports avec `"bundler"` :

```ts
import { ClawdState } from "./types"; // ✅ fonctionne
import { ClawdState } from "./types.js"; // ✅ aussi accepté (optionnel)
```
