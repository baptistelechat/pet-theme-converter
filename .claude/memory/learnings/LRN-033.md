# LRN-033 — HTTP Content-Type headers : toujours normaliser en lowercase avant comparaison

| Pattern observé                                                                                                                                                                                                                         | Contexte                                           | Application future                                                                                                                        |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Les MIME types HTTP sont case-insensitive par RFC 7231 — un serveur non-conforme peut retourner `"Image/PNG"` ou `"IMAGE/webp"`. `startsWith("image/")` sans `.toLowerCase()` produit un faux `ValidationError` sur des images valides. | Review Story 2.1 — P1 détecté par Edge Case Hunter | Toujours écrire `contentType.toLowerCase().startsWith("image/")` ou `.toLowerCase() === "image/png"` pour tout check sur les headers HTTP |
