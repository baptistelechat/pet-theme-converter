# LRN-016 — Encodage UTF-8 Windows pour les commandes Python graphify

| Pattern observé                                                                                                                                   | Contexte                                                | Application future                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Sur Windows, Python utilise cp1252 par défaut — les caractères Unicode (→, ×, –) dans les rapports graphify causent `UnicodeEncodeError: charmap` | Écriture de `GRAPH_REPORT.md` lors du run `/graphify .` | Toujours préfixer avec `$env:PYTHONIOENCODING = "utf-8"` et ajouter `encoding='utf-8'` sur tous les `.read_text()` / `.write_text()` |
