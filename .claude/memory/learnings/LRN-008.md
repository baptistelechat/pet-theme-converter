# LRN-008 — `bmad-create-epics-and-stories` step-03 : vérifier `document_output_language` avant de générer les stories

| Pattern observé                                                                                                                                                             | Contexte                                                                                                       | Application future                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le workflow BMAD génère les stories en anglais (format As a/I want/Given/When/Then) par défaut si `document_output_language` n'est pas explicitement contrôlé avant step-03 | Session `/bmad-create-epics-and-stories` — Baptiste a signalé l'anglais après la génération des stories Epic 1 | Avant de générer la première story en step-03, vérifier `document_output_language` dans `_bmad/bmm/config.yaml` et utiliser le format natif correspondant dès la première story |
