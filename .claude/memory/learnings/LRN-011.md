# LRN-011 — Injection manuelle `.claude/memory/` dans graphify : workaround abandonné

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Contexte                                                                                    | Application future                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Graphify ne scanne pas les dossiers cachés (préfixe `.`) — `.claude/memory/` était absent du graphe. Workaround : injecter manuellement les 35 fichiers dans `.graphify_detect.json` après la détection, avant le lancement des subagents sémantiques. Ce workaround a été utilisé pour les graphes v2 et v3, puis **abandonné** en graphe v4 : les nœuds LRN/EVAL/BDR/BLK polluaient la vault Obsidian et la mémoire n'apportait pas de valeur navigable dans le graphe projet | Graphes v2 (82 nœuds avec mémoire), v3 (125 nœuds avec mémoire), v4 (46 nœuds sans mémoire) | Ne plus injecter `.claude/memory/` — la décision [BDR-013](../decisions/BDR-013.md) entérine l'exclusion permanente. Si un futur projet justifie d'indexer la mémoire, réactiver l'injection manuelle ; pour ce projet, le graphe projet seul est suffisant |
