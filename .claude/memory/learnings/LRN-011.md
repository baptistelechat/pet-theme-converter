# LRN-011 — `graphify` ignore les dossiers cachés — injection manuelle requise pour `.claude/memory/`

| Pattern observé                                                                                                                                                                                                          | Contexte                                                                                                                                | Application future                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `graphify detect` ne scanne pas les dossiers dont le nom commence par `.` (hidden dirs Unix/Windows). Le dossier `.claude/memory/` contenant 35 fichiers riches n'est donc jamais inclus automatiquement dans le graphe. | Session `/graphify .` sur pet-theme-converter — le corpus détecté ne contenait que 7 fichiers, les 35 fichiers mémoire étaient absents. | Après chaque `detect`, vérifier que `.claude/memory/` apparaît dans `.graphify_detect.json`. Si absent, injecter manuellement la liste des fichiers `.md` (hors `.obsidian/`) dans `detect["files"]["document"]` avant de lancer l'extraction. |

## Workaround appliqué

```python
# Après detect(Path(".")), injecter manuellement :
memory_files = list(Path(".claude/memory").rglob("*.md"))
memory_files = [f for f in memory_files if ".obsidian" not in str(f)]
detect["files"]["document"].extend([str(f.resolve()) for f in memory_files])
detect["total_files"] = sum(len(v) for v in detect["files"].values())
```
