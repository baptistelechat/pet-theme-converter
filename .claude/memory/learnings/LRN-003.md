# LRN-003 — Mapping états Petdex→Clawd provisoire, ajustable post-terrain

| Pattern observé                                                                                                                                                                                                                                                           | Contexte                                                                                                                            | Application future                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| La table de correspondance états Petdex (rows 0-8) → états Clawd on Desk est une première approximation intentionnellement provisoire. Le mapping actuel peut ne pas associer les animations les plus pertinentes. Il sera ajusté après tests terrain sur des pets réels. | Baptiste a explicitement signalé que la table RFC n'est pas figée et que les associations seront réévaluées une fois le dev avancé. | Ne pas traiter le mapping comme une vérité immuable dans le code — le rendre facilement modifiable (ex. table de config, pas de hardcode dispersé). |
