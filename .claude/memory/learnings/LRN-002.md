# LRN-002 — Mapping états Petdex → états Clawd on Desk (6 sur 9 ont un équivalent)

| Pattern observé                                                             | Contexte                    | Application future                                                                    |
| --------------------------------------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------- |
| 6 états Petdex mappent vers Clawd, 2 sont ignorés (`run right`, `run left`) | RFC de correspondance états | Implémenter ce mapping dans l'adapter Clawd — ignorer silencieusement les rows 1 et 2 |

Table de correspondance :

| État Clawd     | Déclencheur agent  | État Petdex | Row |
| -------------- | ------------------ | ----------- | --- |
| `idle`         | Aucune session     | `idle`      | 0   |
| `thinking`     | `UserPromptSubmit` | `waiting`   | 6   |
| `working`      | `PreToolUse`       | `running`   | 7   |
| `error`        | `StopFailure`      | `failed`    | 5   |
| `happy`        | `Stop` (succès)    | `waving`    | 3   |
| `notification` | `Notification`     | `review`    | 8   |
| `sleeping`     | Session inactive   | `idle`      | 0   |
| `waking`       | `SessionStart`     | `jumping`   | 4   |

`run right` (row 1) et `run left` (row 2) n'ont pas d'équivalent — ils sont ignorés par l'adapter Clawd.
