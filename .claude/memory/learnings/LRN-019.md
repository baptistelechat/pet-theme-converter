# LRN-019 — `pnpm install`/`add` ne remplace pas les specifiers `"latest"` existants

| Pattern observé                                                                                                                                                                    | Contexte                                                                                             | Application future                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Si `package.json` contient `"pkg": "latest"` et que le package est déjà installé, `pnpm install` et `pnpm add pkg` retournent "Already up to date" sans mettre à jour le specifier | Story 1.1 — `package.json` écrit manuellement avec `"latest"`, pnpm ne l'a pas remplacé par `^x.y.z` | Écrire directement les versions réelles dans `package.json` (depuis l'output d'install), ou utiliser `pnpm add pkg@latest` pour forcer le re-pin |
