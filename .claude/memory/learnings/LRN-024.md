# LRN-024 — Skeleton copier-coller dans Dev Notes → implémentation story sans friction

| Pattern observé                                                                                                                                                                                                             | Contexte                                                                                            | Application future                                                                                                                                                                                                    |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand les Dev Notes d'une story incluent le contenu exact des fichiers à créer (skeleton copier-coller ready), l'implémentation se réduit à une série de `Write` sans diagnostic ni décision — durée < 10 min, zéro blocage | Story 1.2 — 7 fichiers créés en une passe, `pnpm build` + `pnpm typecheck` → exit 0 du premier coup | Lors de la rédaction des stories (`bmad-create-story`), toujours inclure les skeletons complets pour les fichiers non-triviaux (types, interfaces, config) — le coût rédactionnel est récupéré 10× à l'implémentation |
