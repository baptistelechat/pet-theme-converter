# LRN-027 — GitHub community files = anglais par convention, même projet francophone

| Pattern observé                                                             | Contexte                                             | Application future                                              |
| --------------------------------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------- |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` → anglais par défaut | Story 1.3 — décision de Baptiste post-implémentation | Appliquer dès la création, sans attendre une demande post-story |

## Détail

Les "GitHub community health files" sont des conventions GitHub ciblant des contributeurs potentiels du monde entier. Les rédiger en français réduit inutilement l'audience même si `document_output_language` est `Français`.

**Règle à appliquer pour les stories futures :**

| Fichier              | Langue par défaut                     |
| -------------------- | ------------------------------------- |
| `CONTRIBUTING.md`    | Anglais                               |
| `CODE_OF_CONDUCT.md` | Anglais                               |
| `SECURITY.md`        | Anglais                               |
| `README.md`          | Anglais (à confirmer story 4.2)       |
| Story files / BMAD   | Français (`document_output_language`) |
| Mémoire agent        | Français                              |
