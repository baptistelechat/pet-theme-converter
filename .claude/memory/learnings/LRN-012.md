# LRN-012 — `_bmad/` est un framework interne — toujours l'exclure via `.graphifyignore`

| Pattern observé                                                                                                                                                                                                                                                                                                 | Contexte                                                                                                                     | Application future                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Le dossier `_bmad/` contient les scripts Python et configs YAML du framework BMAD (équivalent d'un `node_modules/` ou `.venv/`). L'inclure dans graphify crée des nœuds AST parasites (`deep_merge()`, `_detect_keyed_merge_field()`, etc.) et génère 2 communautés entièrement non pertinentes pour le projet. | Premier run `/graphify .` sur pet-theme-converter — 20 nœuds AST issus de `_bmad/scripts/` et 2 communautés parasites sur 8. | Créer `.graphifyignore` à la racine de tout projet BMAD avec au minimum `_bmad/` et `graphify-out/` avant le premier run graphify. |

## Contenu `.graphifyignore` minimal pour un projet BMAD

```
_bmad/
graphify-out/
```
