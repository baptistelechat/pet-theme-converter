# LRN-051 — Scoper `git diff -- src/` pour les PR descriptions sur branches mixtes

| Pattern observé                                                                                                                                                                            | Contexte                                         | Application future                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `git diff development...epic-2 --stat` retourne 66 fichiers dont 59 hors-code (`.claude/memory/`, stories BMAD, reviews, retrospectives) — scoper `-- src/` réduit à 7 fichiers pertinents | Génération PR description `epic-2 → development` | Toujours utiliser `git diff <base>...<branch> -- src/` comme troisième commande dans `/pr-description-writer` sur ce projet |

## Notes

Sur `pet-theme-converter`, la branche de feature accumule systématiquement des fichiers `.claude/memory/`, `_bmad-output/implementation-artifacts/` et `_bmad-output/planning-artifacts/` qui ne font pas partie de la valeur livrée. Sans le scope `-- src/`, le diff est illisible et les métriques (fichiers modifiés, insertions) sont faussées par la mémoire agent.
