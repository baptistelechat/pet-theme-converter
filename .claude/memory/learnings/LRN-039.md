# LRN-039 — `sliceFrames` : convertir systématiquement en `.png()` pour compatibilité `apngasm-bin`

| Pattern observé                                                                                                                               | Contexte                                                               | Application future                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `sharp(buffer).extract(region).png().toBuffer()` — la conversion `.png()` est obligatoire indépendamment du format source (`.webp` ou `.png`) | Création Story 2.3 — contrat inter-story `sliceFrames` → `encodeAPNGs` | Story 2.4 (`encodeAPNGs`) peut supposer que tous les buffers reçus dans `Record<ClawdState, Buffer[]>` sont au format PNG — pas de vérification de format nécessaire en entrée |

Sans `.png()`, sharp retourne les frames dans le format de la spritesheet source. `apngasm-bin` attend des frames PNG pour produire un APNG. Le forçage en sortie de `sliceFrames` évite une erreur silencieuse ou un comportement indéfini en Story 2.4.
