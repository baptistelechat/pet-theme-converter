# LRN-040 — Convention universelle = patch non-ambigu, pas "décision de design" à déférer

| Pattern observé                                                                                                                                                                                                                        | Contexte                                                                                                                   | Application future                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand une convention universelle de l'écosystème cible existe (ex : anglais pour les messages d'une lib npm publique), la classer comme "patch non-ambigu" et l'appliquer immédiatement — ne pas la déférer comme "décision de design" | Review Story 2.3 — D4 (messages FR) initialement classé "design decision" par l'agent, appliqué après remarque de Baptiste | Avant de classer un finding comme "design decision", vérifier s'il existe une convention documentée et universelle dans l'écosystème. Si oui, c'est un patch. |

## Détail

D4 (messages d'erreur en français) avait été classé `defer - design decision` car la "localisation" semblait ambiguë. Mais la convention npm est sans ambiguïté : les messages exposés aux consumers d'un package public doivent être en anglais. Baptiste l'a signalé immédiatement.

Distinction à retenir :

- **Décision de design** : choix entre options équivalentes sans convention établie (ex : format de retour, nommage d'un concept)
- **Patch non-ambigu** : application d'une convention universelle connue (ex : anglais dans lib publique, JSDoc sur API publique)
