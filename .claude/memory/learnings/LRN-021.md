# LRN-021 — `"moduleResolution": "bundler"` + usage de `process` → nécessite `"types": ["node"]` dans tsconfig

| Pattern observé                                                                                                                                                                                                                                                                                            | Contexte                                                                | Application future                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Avec `"moduleResolution": "bundler"`, TypeScript ne résout pas automatiquement `@types/node` même si le package est installé en devDependencies. L'accès à `process`, `Buffer`, etc. échoue au typecheck avec `TS2591 Cannot find name 'process'`. Fix : ajouter `"types": ["node"]` dans `tsconfig.json`. | Story 1.1 — ajout du check runtime Node version dans `src/cli/index.ts` | Toujours inclure `"types": ["node"]` dans tsconfig dès qu'un fichier accède aux globals Node (`process`, `Buffer`, `__dirname`, etc.) dans un projet avec `"moduleResolution": "bundler"`. |
