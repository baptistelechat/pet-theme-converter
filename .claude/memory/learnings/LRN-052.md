# LRN-052 — Story d'adapter avec artefact testable → validation alpha manuelle sans CLI layer

| Pattern observé                                                                                                                                                                                                                    | Contexte                                                                                                                                                                                                                     | Application future                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Une story d'adapter qui produit un fichier physique (ZIP, dossier) peut être validée manuellement dès sa complétion — sans attendre la CLI layer — en extrayant l'artefact et en l'installant directement dans l'application cible | Story 3.1 — Baptiste a demandé si le ZIP généré par `generateZip` suffisait pour tester dans Clawd on Desk avant Story 3.3 (CLI). Réponse : oui, extraction via `Expand-Archive` dans `%LOCALAPPDATA%\Clawd on Desk\themes\` | Systématiser dans les stories futures : si une story produit un artefact utilisable (ZIP, fichier de config, binaire), documenter dans les Dev Notes la procédure de validation alpha manuelle sans la couche supérieure |
