# LRN-043 — `apngasm-bin` exporte un chemin binaire (string), pas une fonction

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                                       | Application future                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `import apngasm from 'apngasm-bin'` → `typeof apngasm === 'string'` (chemin vers l'exécutable natif). Ne jamais appeler `apngasm()` ou `apngasm.method()`. Invoquer via `execFileAsync(apngasm, [...args])` depuis `node:child_process`. Nécessite un workflow fichiers temporaires : `mkdtemp` → `writeFile` (frames PNG) → `execFileAsync` → `readFile` (APNG) → `rm` dans `finally`. Pas de glob dans les args sur Windows (`execFile` sans shell). | Story 2.4 — recherche API `apngasm-bin` avant implémentation de `encode-apngs.ts`. Package v1.0.3, wraps APNG Assembler v2.91. | Dans toute story ou fonction utilisant `apngasm-bin` : 1) passer les chemins de frames individuellement (pas de glob), 2) nettoyage dans `finally`, 3) si TypeScript manque les types, ajouter `declare module 'apngasm-bin' { const path: string; export default path; }`. |
