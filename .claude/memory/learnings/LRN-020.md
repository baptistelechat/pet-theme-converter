# LRN-020 — Fichiers "standard" déjà présents dans un projet BMAD greenfield

| Pattern observé                                                                                                                                                                                   | Contexte                                                           | Application future                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Dans un projet BMAD greenfield, les fichiers habituellement créés ex-nihilo (`.gitignore`, `.editorconfig`, etc.) peuvent déjà exister avec du contenu custom (ici : entrées Obsidian + graphify) | Story 1.1 — Write `.gitignore` échoué car le fichier existait déjà | Toujours `Read` un fichier avant de le `Write`, même pour les fichiers "standard" — préférer `Edit` (append) plutôt qu'un remplacement complet |
