# LRN-029 — Graphify `--update` LLM peut saturer 100% du budget de session sur un corpus 100% docs

| Pattern observé                                                                                                                                                                                                                                                          | Contexte                                                   | Application future                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le mode `--update` de graphify passe chaque fichier modifié par le LLM pour re-labelliser les communautés. Sur un projet 100% documentaire, chaque update relit tout. Baptiste a atteint 100% de consommation de session Claude Code (5h) — première fois sur ce projet. | Rétrospective Epic 1 — discussion sur la friction graphify | Avant tout run graphify `--update`, évaluer le ratio code/docs du projet. Si docs > 80%, le coût est disproportionné. Signal d'arrêt : session > 50% conso après un seul update. |
