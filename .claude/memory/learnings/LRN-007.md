# LRN-007 — BMAD step-04 (decisions) : filtrer les catégories non pertinentes pour un CLI tool

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                        | Contexte                                                                                                | Application future                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Le step-04 de `bmad-create-architecture` propose 5 catégories génériques (Data, Auth, API, Frontend, Infrastructure). Pour un CLI pur sans DB, API ni frontend, 3 catégories sur 5 ne s'appliquent pas. Identifier explicitement les catégories pertinentes en amont et remplacer les génériques par des catégories spécifiques au projet (pipeline interne, contrat public, infra/distribution) rend la session beaucoup plus fluide. | Session `/bmad-create-architecture` sur `pet-theme-converter` — CLI TypeScript sans couche réseau ni UI | Pour tout projet CLI, script, ou outil en ligne de commande : avant d'entrer dans step-04, mapper les catégories BMAD au type de projet et écarter les non-pertinentes. Remplacer par : (1) architecture interne du pipeline, (2) interface(s) publique(s), (3) infrastructure et distribution. |
