# LRN-010 — Coverage Map ≠ couverture complète des ACs UX : vérifier le QUAND et COMMENT, pas seulement le QUOI

| Pattern observé                                                                                                                                                                                                                                                                                                                                                         | Contexte                                                                                             | Application future                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Un FR marqué "couvert" dans le Coverage Map d'un Epic peut avoir une story assignée avec des ACs insuffisants pour décrire le flux UX concret. Exemple : FR18 référencée dans Stories 3.2 + 3.3 mais aucun AC ne décrivait QUAND et COMMENT l'utilisateur saisit le chemin Clawd manuellement — les ACs supposaient le chemin "déjà fourni" sans décrire l'interaction. | Session `/bmad-check-implementation-readiness` — step-03 Epic Coverage + step-05 Epic Quality Review | Lors de tout `bmad-check-implementation-readiness`, vérifier pour chaque FR d'interaction utilisateur (prompts, saisies, choix conditionnel) que les ACs couvrent explicitement : (1) la condition de déclenchement, (2) le flux d'interaction, (3) la validation/gestion d'erreur. Ne pas se contenter du Coverage Map. |
