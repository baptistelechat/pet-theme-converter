# LRN-046 — Frame counts Petdex non uniformes par état → blank frame si on découpe toujours 8 colonnes

| Pattern observé                                                                                                                                                                                                                                                                                                                                                     | Contexte                                                                                                     | Application future                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Les 9 lignes d'une spritesheet Petdex n'ont pas toutes 8 frames valides (counts réels : 6/8/8/4/5/8/6/6/6). Les colonnes vides après le dernier frame réel sont des PNG transparents. Si `STATE_MAPPING` indique `frames: 8` pour un état qui n'en a que 4, `sliceFrames` inclut 4 frames transparentes → apngasm les encode → blank flash à la fin de l'animation. | Story 2.4 — inspection visuelle des APNGs générés, Baptiste a compté les frames par ligne sur la spritesheet | Toujours utiliser les frame counts exacts de [BDR-022](../decisions/BDR-022.md) dans `STATE_MAPPING`. Ne jamais remettre `frames: 8` uniformément. |
