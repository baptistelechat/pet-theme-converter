# LRN-018 — `git rm --cached` crée un état hybride visible dans VS Code jusqu'au commit

| Pattern observé                                                                                                                                                                                                                                                                           | Contexte                                                                                                                                                                                 | Application future                                                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Après `git rm -r --cached <dir>`, les fichiers qui existaient déjà dans git apparaissent en couleur (non grisés) dans VS Code — état hybride "staged deletion + fichier non tracké recréé" — le gris (ignoré par `.gitignore`) ne s'affiche qu'après le commit qui finalise le détracking | Baptiste a ajouté `graphify-out/` au `.gitignore` + lancé `git rm --cached`, puis s'est inquiété que la commande n'avait pas fonctionné car VS Code montrait encore des fichiers colorés | Expliquer dès le départ : `git rm --cached` a bien fonctionné (les `D ` dans `git status` le confirment) — le commit est la seule étape qui résout l'affichage VS Code |
