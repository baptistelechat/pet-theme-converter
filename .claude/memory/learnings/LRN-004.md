# LRN-004 — `bmad-product-brief` court-circuitable quand RFC complet + mémoire structurée

| Pattern observé                                                                                                                                                                            | Contexte                                              | Application future                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Quand un projet dispose d'un RFC complet ET d'une mémoire agent structurée, les stages 1-2 du workflow (intent + contextual discovery) peuvent être sautés pour aller directement au draft | Session `/bmad-product-brief` sur pet-theme-converter | Prioriser la lecture RFC + mémoire en amont — si les deux sont présents et cohérents, annoncer le draft direct sans poser de questions de découverte |

Le brief produit (8 sections, ~1,5 page) était cohérent avec le RFC sans aucune question de clarification intermédiaire. La mémoire agent a servi de substitut complet aux stages de discovery.
