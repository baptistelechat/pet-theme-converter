# LRN-005 — `python3` intercepté par le stub Microsoft Store sur Windows — utiliser `python` à la place

| Pattern observé                                                                                                                                                                               | Contexte                                                 | Application future                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `python3 --version` retourne le stub Microsoft Store ("Python est introuvable...") mais `python --version` → Python 3.14.3 ✅. Le script `resolve_customization.py` fonctionne avec `python`. | Activation de skills BMAD sur machine Windows (Baptiste) | Toujours invoquer `python` (sans le 3) pour les scripts BMAD. Ne jamais utiliser `python3`. |

**Cause** : Windows crée un alias `python3.exe` qui redirige vers le Microsoft Store. `python.exe` pointe lui vers l'installation réelle (Python 3.14.3 via Microsoft Store ou standalone).

**Commande correcte** :

```bash
python "_bmad/scripts/resolve_customization.py" --skill "{skill-root}" --key workflow
```

**Fallback manuel** (si le script échoue malgré tout) : lire `{skill-root}/customize.toml`, puis vérifier l'absence d'overrides dans `_bmad/custom/{skill-name}.toml` et `_bmad/custom/{skill-name}.user.toml`.
