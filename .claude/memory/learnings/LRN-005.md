# LRN-005 — `resolve_customization.py` inutilisable sur Windows sans Python — fallback manuel suffisant

| Pattern observé                                                                                                                   | Contexte                                                | Application future                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Le script BMAD `resolve_customization.py` échoue silencieusement sur Windows quand Python n'est pas installé dans le PATH système | Activation de `/bmad-product-brief` sur machine Windows | Lire `customize.toml` directement sans passer par le script — les defaults suffisent en l'absence de fichiers d'override team/user |

Fallback appliqué : lecture de `{skill-root}/customize.toml` uniquement (pas d'overrides détectés dans `_bmad/custom/`). Résultat identique au script pour ce cas standard.
