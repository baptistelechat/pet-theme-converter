# BLK-009 — `build_from_json()` sans support `--update` — `build_merge()` est la bonne API

| Friction                                                                                          | Cause réelle                                                                                                  | Solution                                                                        | Statut |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------ |
| `build_from_json(existing_graph=...)` → `TypeError: unexpected keyword argument 'existing_graph'` | `build_from_json` reconstruit un graphe depuis zéro — `build_merge` est la fonction dédiée au mode `--update` | Utiliser `build_merge(new_chunks=[extract], graph_path=..., prune_sources=...)` | résolu |

## Détail

Lors du pipeline graphify `--update`, l'appel `build_from_json(extract, existing_graph=existing, output_dir=...)` a échoué avec `TypeError`. Diagnostic : inspection de `graphify.build` via `pkgutil` → `build_merge` trouvé avec la signature correcte pour le mode incrémental. Résolu en une tentative.

Signature complète : `build_merge(new_chunks: list[dict], graph_path: str | Path, prune_sources: list[str] | None, *, directed: bool, dedup: bool, dedup_llm_backend: str | None) -> nx.Graph`

Deux autres mismatches API détectés dans la même session :

- `graphify.analyze` n'exporte pas `analyze` mais `god_nodes` + `surprising_connections`
- `report.generate` nécessite `detect_result` avec les clés `total_files` et `total_words`
