# BLK-004 — `UnicodeEncodeError` cp1252 lors de l'écriture du rapport graphify sur Windows

| Friction                                                                     | Cause réelle                                                                                                          | Solution                                                                                                                          | Statut |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------ |
| `UnicodeEncodeError: 'charmap' codec can't encode character '→'` à l'étape 4 | Windows utilise cp1252 par défaut pour les I/O fichiers Python — les caractères `→`, `×`, `–` ne sont pas dans cp1252 | `$env:PYTHONIOENCODING = "utf-8"` avant chaque commande Python + `encoding='utf-8'` sur tous les `.read_text()` / `.write_text()` | résolu |
