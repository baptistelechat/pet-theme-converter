# BLK-007 — `"latest"` dans `package.json` non remplacé par pnpm

| Friction                                                                                                                                               | Cause réelle                                                                                                                       | Solution                                                                                  | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------ |
| Après `pnpm install`, `package.json` conservait `"pkg": "latest"` au lieu de `"^x.y.z"` ; `pnpm add pkg` a retourné "Already up to date" sans corriger | pnpm ne met à jour les specifiers que lors d'un vrai `pnpm add` sur un package absent — si la clé existe déjà, il ne la touche pas | Édition manuelle de `package.json` avec les versions réelles tirées de l'output d'install | résolu |
