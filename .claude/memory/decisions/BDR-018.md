# BDR-018 — CONTRIBUTING.md rédigé en anglais

**Date :** 2026-05-06
**Statut :** actif

## Décision

`CONTRIBUTING.md` est rédigé en **anglais**, contrairement à `document_output_language: Français` défini dans `_bmad/bmm/config.yaml`.

## Raison

`CONTRIBUTING.md` est une convention GitHub ciblant des contributeurs potentiels du monde entier. Le rédiger en français réduirait inutilement l'audience. L'accessibilité internationale prime sur la cohérence de langue interne du projet.

## Portée

- S'applique uniquement à `CONTRIBUTING.md` et aux futurs fichiers GitHub community health files (`CODE_OF_CONDUCT.md`, `SECURITY.md`, etc.).
- Les story files, planification BMAD, et mémoire agent restent en français.
- `README.md` (Story 4.2) devra aussi être évalué sous ce même prisme.

## Références

- Story 1.3 Dev Notes : _"Si Baptiste souhaite passer en anglais pour maximiser l'accessibilité internationale, c'est une décision post-story."_
