# BDR-013 — Workflow graphify : hook post-commit retiré, mise à jour manuelle via `--update`

| Décision                                                             | Pourquoi                                                                                                                                                          | Alternatives considérées                  | Statut |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- | ------ |
| Retirer le hook post-commit graphify, lancer `--update` manuellement | Le hook ne traite que les fichiers code (AST, sans LLM) — le projet est 100% docs ; le hook n'apportait rien et obligeait quand même un run manuel pour les `.md` | Garder le hook + run manuel pour les docs | actif  |
