# BDR-001 — Format de sortie APNG plutôt que SVG animé

| Décision                                        | Pourquoi                                                                                     | Alternatives considérées                                              | Statut |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------ |
| Générer uniquement des APNG pour tous les états | La source est un `.webp` raster — convertir en SVG ajouterait une couche inutile sans valeur | SVG animé (rejeté : source raster), GIF (rejeté : qualité inférieure) | actif  |

Pipeline retenu : `webp → frames PNG → APNG`

Clawd on Desk accepte les APNG pour tous les états y compris `idle` — le SVG n'est requis que pour l'eye tracking natif, feature optionnelle non couverte par ce convertisseur.
