# BDR-003 — Architecture Core + Output Adapters interchangeables

| Décision                                                          | Pourquoi                                                                              | Alternatives considérées                       | Statut |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------- | ------ |
| Séparer la logique Core (découpe spritesheet) des Output Adapters | Permet d'ajouter de nouvelles cibles (Clyde, etc.) sans toucher au core de conversion | Monolithe tout-en-un (rejeté : non extensible) | actif  |

Flux : `[ spritesheet source ] → [ Core Converter ] → [ Output Adapter ]`

Le Core est agnostique — il prend une spritesheet, la découpe en frames et assemble des APNGs via un `SpriteManifest` auto-détecté depuis le format standard Petdex (grille 8×9, 192×208px).
