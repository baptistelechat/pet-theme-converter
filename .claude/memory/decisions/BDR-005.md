# BDR-005 — Cible sources : toutes marketplaces Codex-compatibles, pas seulement Petdex

| Décision                                                                                                                                                                                                                                                                | Pourquoi                                                                                                                                                                     | Alternatives considérées                                                    | Statut |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------ |
| Le convertisseur accepte toute spritesheet respectant le format standard Codex (grille 9×8, 192×208px), quelle que soit la marketplace source (Petdex, futures galleries, fichiers locaux...). Petdex est citée en exemple dans la doc, pas comme contrainte technique. | Éviter un couplage artificiel à une seule marketplace alors que le format est standardisé par Codex. Maximise la surface d'utilisation sans effort technique supplémentaire. | Limiter à Petdex uniquement (trop restrictif, ferme des portes inutilement) | actif  |
