# BDR-009 — Interface OutputAdapter figée : AdapterInput reçoit des APNGs pré-encodés

| Décision                                                                                   | Pourquoi                                                                                                                              | Alternatives considérées                                                                                     | Statut |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------ |
| `AdapterInput` reçoit `apngs: Record<ClawdState, Buffer>` (APNGs déjà encodés par le Core) | Le Core reste responsable de l'encodage ; l'adapter ne fait que packager ; interface stable et simple pour les contributeurs externes | `AdapterInput` avec frames brutes `sharp.Sharp[]` (adapter contrôle l'encodage, plus complexe, moins stable) | actif  |
