# BDR-008 — Pipeline fonctionnel pur + callbacks `onProgress`

| Décision                                                                                                                                       | Pourquoi                                                                                       | Alternatives considérées                                                                                                                      | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Pipeline de traitement en fonctions pures `(input) => Promise<output>` avec `onProgress?: ProgressCallback` optionnel injecté par la CLI layer | Testable à l'unité, Core découplé de `@clack/prompts`, chaque étape remplaçable indépendamment | Classe `Converter` orchestratrice (plus de boilerplate, state caché), pipeline fonctionnel sans callback (barre de progression non découplée) | actif  |
