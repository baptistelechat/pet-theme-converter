# BDR-012 — `"moduleResolution": "bundler"` pour TypeScript + tsup

| Décision                                                                             | Pourquoi                                                                                                                                                                                                      | Alternatives considérées                                                                                                                          | Statut |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Utiliser `"module": "ESNext"` + `"moduleResolution": "bundler"` dans `tsconfig.json` | tsup est le bundler — `"Node16"` impose des extensions `.js` sur tous les imports relatifs, ce qui est verbeux et inattendu. `"bundler"` délègue la résolution à tsup et autorise les imports sans extension. | `"module": "Node16"` + `"moduleResolution": "Node16"` (rejeté — contraint les imports à `.js`, adaptés à du code Node.js sans bundler uniquement) | actif  |

S'applique à **toutes** les stories TypeScript du projet. Toute configuration `tsconfig.json` créée dans ce repo doit utiliser `"moduleResolution": "bundler"`.
