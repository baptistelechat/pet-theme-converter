# BDR-010 — `archiver` comme librairie ZIP dans `clawd.ts`

| Décision                                                                                                  | Pourquoi                                                                            | Alternatives considérées                                                                 | Statut |
| --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------ |
| Utiliser le package npm `archiver` pour créer le fichier `<nom-pet>-clawd-theme.zip` dans l'adapter Clawd | Standard de facto, API simple (3 lignes), < 5 kB d'overhead, pas de binaires natifs | `jszip` (pur JS mais plus lent), `node:zlib` + `fs` natif (zéro dépendance mais verbeux) | actif  |
