# BDR-019 — Types intermédiaires Core exportés depuis leur module source (pas `types.ts`)

| Décision                                                                                                                                             | Pourquoi                                                                                                                                                                                                                               | Alternatives considérées                                                                                                                                   | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Les types intermédiaires du pipeline Core (ex : `GridInfo`) sont exportés depuis leur module source (`detect-grid.ts`), jamais depuis `src/types.ts` | `types.ts` est réservé à l'API publique des adapters (`OutputAdapter`, `AdapterInput`, etc.). Les types de flux interne Core ne concernent pas les contributeurs externes — les centraliser dans `types.ts` polluait le contrat public | Tout centraliser dans `types.ts` (rejeté — API publique polluée) ; créer `src/types/internal.ts` (rejeté — prématuré pour un projet à 14 fichiers en v0.1) | actif  |

## Application

- `GridInfo` → export depuis `src/core/detect-grid.ts`
- `sliceFrames` (Story 2.3) importera `GridInfo` via `import type { GridInfo } from './detect-grid'`
- `cli/messages.ts` (Story 3.4) importera `GridInfo` via `import type { GridInfo } from '../core/detect-grid'`
- Règle générale : si le type ne fait pas partie du contrat `OutputAdapter`, il ne va pas dans `types.ts`
