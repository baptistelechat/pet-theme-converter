# BDR-006 — CLI 100% interactif, pas de fichier de configuration en v0.1

| Décision                                                                 | Pourquoi                                                                                                     | Alternatives considérées                                                         | Statut |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------ |
| Aucun fichier de config dédié en v0.1 — tout passe par les 3 prompts CLI | Maintenir la promesse "zéro friction" : un utilisateur découvrant l'outil peut l'utiliser sans documentation | Fichier `.pet-converter.json` (rejeté : overhead inutile pour un usage ponctuel) | actif  |

Chaque exécution repart de zéro via les prompts. Pas d'état persistant entre les conversions. Le mode non-interactif via flags (`--source`, `--name`, `--output`) est prévu en v2+ — délibérément hors scope v0.1.
