# BDR-004 — Gestion des spritesheets hors-standard : warning + grille 9×8 par défaut

| Décision                                                                                                                                                                                                                                                     | Pourquoi                                                                                                               | Alternatives considérées                                                                                                  | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------ |
| Assumer grille 9×8 / 192×208px par défaut. Si les dimensions ne correspondent pas, afficher un warning "résultats non garantis" et continuer quand même. Pas de rejet. Futur : param CLI `--rows/--cols/--frame-width/--frame-height` pour override (v0.2+). | Couvre la majorité des spritesheets Codex-compatibles sans bloquer les edge cases. L'utilisateur est averti du risque. | Rejet strict si non-standard (trop restrictif) ; `--custom-manifest` dès v0.1 (trop tôt, ajoute de la complexité inutile) | actif  |
