# BDR-002 — Distribution via package npm indépendant + mini PRs de doc

| Décision                                                     | Pourquoi                                                                               | Alternatives considérées                                                              | Statut |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------ |
| Publier sur npm + faire des PRs de 2 lignes dans les READMEs | 100% autonome, pas de dépendance sur les mainteneurs des autres repos pour fonctionner | PR côté Clawd (couplé, dépend du mainteneur), PR côté Petdex (Codex-first, incertain) | actif  |

Séquence prévue :

1. `npm publish pet-theme-converter`
2. PR Petdex → mention dans README
3. PR Clawd on Desk → mention dans `docs/guides/`
4. PR Clyde → mention dans README

Les PRs "ajout d'une ligne de doc" sont acceptées en 24h. Les PRs "ajout de code" peuvent traîner des semaines.
