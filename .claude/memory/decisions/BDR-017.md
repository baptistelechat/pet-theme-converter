# BDR-017 — Arrêt définitif de graphify sur pet-theme-converter

| Décision                                                                                   | Pourquoi                                                                                                                                        | Alternatives considérées                                                                             | Statut                                                           |
| ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Supprimer `graphify-out/` et `.graphifyignore` — ne plus maintenir le graphe sur ce projet | Projet 100% docs : le graphe nécessite un run manuel + injection `.claude/memory/` après chaque session. Coût de maintenance > valeur produite. | Continuer `--update` manuel ([BDR-013](BDR-013.md)) / garder outputs trackés ([BDR-014](BDR-014.md)) | actif (supersède [BDR-013](BDR-013.md) et [BDR-014](BDR-014.md)) |

## Détail

Le graphify v5 (`--update` du 2026-05-05) a été le dernier run : 90 nœuds, 207 edges, 13 communautés. Le projet pet-theme-converter est structurellement un corpus BMAD 100% documentaire — la valeur du graphe était réelle lors des sessions d'exploration initiales (v1→v4), mais la maintenance récurrente (injection `.claude/memory/` à chaque run, run manuel obligatoire, pas d'automatisation possible sur un projet purement docs) dépasse le bénéfice.

Les learnings accumulés sur graphify ([LRN-011](../learnings/LRN-011.md) à [LRN-017](../learnings/LRN-017.md)) restent valides et réutilisables sur d'autres projets.
