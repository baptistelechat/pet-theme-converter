# BDR-020 — Messages d'erreur du pipeline Core en anglais (lib publique npm)

| Décision                                                                                                                     | Pourquoi                                                                                                                                             | Alternatives considérées                                                                                                                                    | Statut |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Tous les messages d'erreur (`ValidationError`, `FetchError`) et labels `onProgress` des modules Core sont rédigés en anglais | `pet-theme-converter` est un package npm public — l'anglais est la convention universelle pour les messages exposés aux consumers d'une bibliothèque | Messages en français (cohérent avec `communication_language: Français`) — écarté car les erreurs remontent au consumer du package, pas seulement à Baptiste | actif  |

## Contexte

Découvert lors de la review Story 2.3 (D4). Les messages avaient été écrits en français par défaut (cohérent avec `document_output_language`). Lors de la résolution opportuniste post-review, Baptiste a confirmé l'application immédiate. Les 3 modules concernés ont été mis à jour dans la même session :

- `src/core/fetch-spritesheet.ts` — 7 messages traduits
- `src/core/detect-grid.ts` — 3 messages traduits
- `src/core/slice-frames.ts` — 3 messages traduits

## Application future

Pour toute nouvelle fonction Core (`encode-apngs.ts`, etc.), écrire directement les messages en anglais. Pas besoin de traduction rétroactive — la règle s'applique dès maintenant.
