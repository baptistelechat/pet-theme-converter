# BDR-007 — Timeout fetch réseau = 30 secondes

| Décision                                                                 | Pourquoi                                                                                                           | Alternatives considérées                                                              | Statut |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ------ |
| Timeout de 30 secondes pour le téléchargement d'une spritesheet distante | Éviter les hangs indéfinis sur des URLs lentes ou inaccessibles — valeur suffisante pour des fichiers image légers | 10s (trop court sur connexion lente), configurable v0.1 (rejeté : complexité inutile) | actif  |

Au-delà de 30 secondes, le CLI interrompt le fetch et affiche un message d'erreur explicite (exit code 1). Une option de timeout configurable est envisageable en v0.2+ si des cas réels le justifient.
