# BDR-016 — Règles workflow post-review dans CLAUDE.md (pas dans les custom toml skills)

| Décision                                                                                                                                                     | Pourquoi                                                                                                                                          | Alternatives considérées                                                                            | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------ |
| Stocker les règles comportementales du workflow de review (fichier dédié, résolution opportuniste deferred-work, format emoji, cochage ACs) dans `CLAUDE.md` | CLAUDE.md est chargé à chaque session quelle que soit l'entrée ; les custom toml skills ne s'activent qu'au démarrage du skill `bmad-code-review` | `_bmad/custom/bmad-code-review.toml` (rejeté — activation conditionnelle, oubliable entre sessions) | actif  |

Règles inscrites dans CLAUDE.md :

1. Findings → fichier dédié `reviews/` (jamais dans story file)
2. Story `done` → cocher ACs dans `epics.md`
3. Fin de review → résolution opportuniste des items 🔵 dans `deferred-work.md`
4. Mise à jour `deferred-work.md` à chaque review (format 🔵/✅/🚫)
