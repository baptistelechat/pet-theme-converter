# Contributing to pet-theme-converter

Welcome! This guide explains how to create and submit an **Output Adapter** to integrate `pet-theme-converter` with a new companion application.

An adapter receives the 8 APNGs generated by the Core and delivers them in the format expected by your app (ZIP archive, direct install, cloud upload, etc.).

---

## Project Setup

**Prerequisites:** Node.js ≥ 18.x · pnpm ≥ 8.x · TypeScript (basic knowledge)

```bash
# 1. Clone the repo
git clone https://github.com/baptistelechat/pet-theme-converter.git
cd pet-theme-converter

# 2. Install dependencies
pnpm install

# 3. Run in development mode (no compilation)
pnpm dev

# 4. Build the project
pnpm build

# 5. Test locally before publishing
pnpm link
```

## Architecture

The project is structured in **3 independent layers**:

```
src/
├── types.ts       ← Shared public interfaces (root of the graph — no internal dependencies)
├── core/          ← Conversion pipeline (fetch → detect → slice → encode)
├── adapters/      ← Output Adapters (one file per companion app)
└── cli/           ← Interactive user interface (@clack/prompts)
```

### Module boundary rules (mandatory)

| Layer            | Can import from                                | Cannot import from            |
| ---------------- | ---------------------------------------------- | ----------------------------- |
| `src/types.ts`   | _(no internal imports)_                        | —                             |
| `src/core/*`     | `src/types.ts` only                            | `src/cli/*`, `src/adapters/*` |
| `src/adapters/*` | `src/types.ts` only                            | `src/cli/*`, `src/core/*`     |
| `src/cli/*`      | `src/core/*`, `src/adapters/*`, `src/types.ts` | —                             |

> ⚠️ **`@clack/prompts` is imported only in `src/cli/`.** Never import it in an adapter or in the Core.

## Writing an Adapter

An adapter is a TypeScript file in `src/adapters/` that implements the `OutputAdapter` interface defined in [`src/types.ts`](src/types.ts).

### `OutputAdapter` interface

```typescript
import type { OutputAdapter, AdapterInput, AdapterOutput } from "../types";

export const myAdapter: OutputAdapter = {
  async generate(input: AdapterInput): Promise<AdapterOutput> {
    // Your implementation here
    return {
      mode: "zip",
      path: "/absolute/path/to/output.zip",
      warnings: [], // optional
    };
  },
};
```

### What the adapter receives — `AdapterInput`

| Field       | Type                         | Description                                                                |
| ----------- | ---------------------------- | -------------------------------------------------------------------------- |
| `apngs`     | `Record<ClawdState, Buffer>` | 8 pre-encoded APNGs, one per Clawd state. Each Buffer is non-empty.        |
| `manifest`  | `ThemeManifest`              | Metadata: `name`, `compatibleWith` (e.g. `"clawd-on-desk@1.x"`), `version` |
| `outputDir` | `string`                     | **Absolute** path of the output directory (create your files here)         |

The states available in `ClawdState`: `idle` · `thinking` · `working` · `error` · `happy` · `notification` · `sleeping` · `waking`.

### What the adapter must return — `AdapterOutput`

| Field      | Type                    | Description                                                       |
| ---------- | ----------------------- | ----------------------------------------------------------------- |
| `mode`     | `'zip' \| 'install'`    | Delivery mode used by this adapter                                |
| `path`     | `string`                | **Absolute** path to the generated file or directory              |
| `warnings` | `string[]` _(optional)_ | Non-blocking warnings to display to the user after the conversion |

The `warnings` field is used to signal non-critical situations — for example:

- `"Unknown target version — theme generated without compatibility guarantee"`
- `"Output directory created automatically"`

These messages are passed to the CLI layer and displayed to the user without interrupting the conversion.

### Error handling

**Never** use `throw new Error('message')` directly. Extend the typed classes from `src/types.ts`:

| Class             | `exitCode` | When to use                                 |
| ----------------- | ---------- | ------------------------------------------- |
| `FetchError`      | `1`        | Retrieval failure (network, file not found) |
| `ValidationError` | `2`        | Invalid format or corrupted data            |
| `InstallError`    | `3`        | Failure during theme write or install       |

```typescript
import { InstallError } from "../types";

throw new InstallError("Output directory is not writable");
```

### Reference adapter

> _See [`src/adapters/clawd.ts`](src/adapters/clawd.ts) — implemented in Epic 3._

This file will be the reference adapter for **Clawd on Desk**. It implements: automatic Clawd directory detection per OS (Windows / macOS / Linux), ZIP archive generation via `archiver`, and direct install into the application's `themes/` directory.

## Submitting an Adapter

### 1. Register the adapter in `src/cli/index.ts`

Add your adapter to the output mode selection menu in `src/cli/index.ts`:

```typescript
// Import your adapter
import { myAdapter } from "../adapters/my-adapter";

// Add your adapter to the options presented to the user
// (follow the registration pattern visible in src/cli/index.ts once Epic 3 is implemented)
```

> ℹ️ The full registration pattern will be visible in `src/cli/index.ts` from Epic 3 onwards. In the meantime, add the import and follow the existing code to integrate your adapter into the CLI prompts.

### 2. Open a Pull Request

1. Fork the repo and create a dedicated branch:
   ```bash
   git checkout -b adapter/app-name
   ```
2. Create your adapter in `src/adapters/app-name.ts`
3. Register it in `src/cli/index.ts`
4. Verify that `pnpm build` passes without errors (`exit 0`)
5. Open a PR to `main` including:
   - The name of the targeted companion application
   - The app version targeted by your adapter
   - A description of the delivery mode (ZIP, direct install, etc.)
